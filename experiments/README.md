# Experimentos

Cada experimento debe identificar explícitamente la configuración de estrategia,
capital virtual, cantidad y costes de simulación.

## Objetivo

Permitir comparar configuraciones de forma reproducible y separar el conjunto
de entrenamiento del conjunto fuera de muestra.

No se deben seleccionar parámetros únicamente por el resultado del conjunto de
test. Los resultados de simulación tampoco implican rendimiento futuro.
