# Gestión de riesgo

El módulo `risk/` será el punto de control previo a cualquier ejecución.

La implementación futura deberá poder rechazar una operación antes de que
llegue a la capa MT5. Los límites de riesgo no deben ser modificables
libremente por un agente de IA.

Por ahora este módulo no calcula riesgo ni envía órdenes.
